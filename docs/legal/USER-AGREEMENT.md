## 3. 加密保护的范围与限制

3.1 **加密保护范围**：在端到端加密正常实现且未被破坏的前提下，消息内容、文件内容在传输过程中以密文形式经过服务器，运营方在技术上不持有解密密钥。

3.2 **明确不在加密保护范围内的内容**包括但不限于：

（a）通信元数据，例如连接时间、IP 地址、数据包大小、连接频率等；

（b）您设备上的本地明文数据、截图、缓存、通知内容；

（c）接收方设备被入侵、被控制或主动泄露的内容；

（d）您主动向第三方披露、转发或公开的内容；

（e）您使用第三方输入法、云剪贴板、云备份、屏幕共享等外部服务导致泄露的内容。

3.3 **技术不可访问声明**：根据当前版本的架构设计，运营方不持有您的端到端加密私钥，因此在技术上通常无法读取您的消息明文，也无法应第三方要求直接解密您的通信内容。但该声明不排除因您设备被入侵、密钥泄露、软件漏洞、元数据分析或法律强制手段导致信息被获取的风险。

3.4 **加密不等于绝对安全**：当前 Schat 代码可能未经第三方密码学审计。**请勿将本服务用于高价值机密、国家秘密、商业秘密、生命健康紧急通讯或其他一旦泄露可能造成严重后果的场景。**
